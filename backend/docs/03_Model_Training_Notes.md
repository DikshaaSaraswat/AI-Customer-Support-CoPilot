## TF-IDF Feature Extraction

Machine learning models cannot process raw text directly.

TF-IDF (Term Frequency–Inverse Document Frequency) converts the cleaned ticket text into numerical feature vectors while assigning greater importance to informative words and reducing the influence of very common words.

### TF-IDF Output

- Training Matrix Shape: **(13068, 5367)**
- Testing Matrix Shape: **(3267, 5367)**

The TF-IDF vectorizer learned a vocabulary of **5,367 unique terms** from the training data.

Each customer support ticket is now represented as a numerical feature vector, making it suitable for machine learning algorithms.

## Logistic Regression Model

Train a baseline Logistic Regression model to classify customer support tickets into their respective support queues.


## Baseline Model

A Logistic Regression classifier was selected as the baseline model for queue prediction.

Logistic Regression performs well on high-dimensional sparse text data generated by TF-IDF and serves as a strong benchmark before comparing more advanced algorithms.


## Queue Prediction

## Experiment 1: Improved TF-IDF

To improve the baseline model, the TF-IDF vectorizer was configured with additional parameters:

- `stop_words="english"` to remove common English words.
- `ngram_range=(1,2)` to include both single words (unigrams) and two-word phrases (bigrams).
- `min_df=2` to ignore extremely rare words appearing in only one document.

### TF-IDF Output

- Training Matrix Shape: **(13068, 47715)**
- Testing Matrix Shape: **(3267, 47715)**

The vocabulary increased significantly because bigrams were included, allowing the model to learn meaningful phrases such as "credit card", "password reset", and "billing issue".

### Model Performance

| Experiment | Accuracy |
|------------|---------:|
| Baseline TF-IDF | **47.69%** |
| Improved TF-IDF | **54.12%** |

The improved TF-IDF configuration increased the model accuracy by approximately **6.4 percentage points**, demonstrating that better feature engineering can significantly improve text classification performance.

## Model Evaluation using Confusion Matrix

The confusion matrix provides a detailed visualization of the model's predictions by comparing the predicted ticket queues with the actual ticket queues.

It helps identify which ticket categories are correctly classified and which categories are frequently confused with one another.

### Key Observations

- The Logistic Regression model performed well for larger classes such as **Technical Support**, **Billing and Payments**, and **Product Support**.
- **Technical Support** achieved the highest number of correct predictions, indicating that the model learned this category effectively.
- Smaller classes such as **General Inquiry**, **Human Resources**, and **Returns and Exchanges** were frequently misclassified due to having fewer training samples.
- A significant number of tickets from different categories were predicted as **Technical Support**, indicating the effect of class imbalance in the dataset.
- The confusion matrix highlights opportunities for future improvements, including class balancing, advanced feature engineering, and evaluation of alternative machine learning models.
